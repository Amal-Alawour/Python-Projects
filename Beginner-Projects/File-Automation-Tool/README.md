# 🗂️ File Automation Tool

## 📌 Project Overview

File Automation Tool is a Python application that automatically organizes files inside a folder based on their file types.

This project demonstrates how Python can be used to automate daily tasks and improve productivity by reducing manual file organization.

---

## 🚀 Features

- Automatically organize files into folders
- Detect file extensions
- Create folders automatically
- Move files based on categories

Supported categories:

- Images
- Documents
- Excel Files
- Videos
- Other Files

---

## 🛠 Technologies Used

- Python 3
- OS Module
- Shutil Module

---

## 📚 Concepts Practiced

- File Handling
- Operating System Operations
- Automation with Python
- Functions
- Loops
- Conditional Statements
