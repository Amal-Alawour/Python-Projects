# 🎓 Student Management System

## 📌 Project Overview

Student Management System is a Python-based application designed to manage student information using a simple database system.

This project demonstrates how Python can be used to build practical applications for managing and organizing data.

---

## 🚀 Features

- Add new students
- View student records
- Update student information
- Delete student records
- Store data using SQLite database

---

## 🛠 Technologies Used

- Python 3
- SQLite Database

---

## 📚 Concepts Practiced

- Python Functions
- Database Connection
- SQL Queries
- CRUD Operations
- User Input Handling
- Data Management

---

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Run:

```bash
python student_management.py
