# 🎓 Student Management System

## 📌 Project Overview

Student Management System is a Python-based application designed to manage student records efficiently using an SQLite database.

The project demonstrates how Python can be used to build practical data management applications with database integration and CRUD operations.

This project reflects my interest in combining programming, data management, and real-world digital solutions.

---

## 🚀 Features

✅ Add new student records  
✅ View student information  
✅ Update student details  
✅ Delete student records  
✅ Store and retrieve data using SQLite database  
✅ Manage student information through structured operations

## ▶️ How to Run

1. Make sure Python 3 is installed.

2. Clone the repository:

```bash
git clone https://github.com/Amal-Alawour/Python-Projects.git
```

3. Navigate to the project folder.

4. Run:

```bash
python student_management.py
```
