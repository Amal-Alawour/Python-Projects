# 🧮 Simple Calculator

## 📌 Project Overview

Simple Calculator is a Python-based application that performs basic mathematical operations through a command-line interface (CLI).

This project demonstrates Python programming fundamentals including functions, user input handling, conditional statements, loops, and error handling.

---

## 🚀 Features

- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero
- Continuous calculations
- User input validation

---

## 🛠 Technologies Used

- Python 3

---

## 📚 Concepts Practiced

- Python Functions
- Variables
- User Input
- Conditional Statements
- Loops
- Error Handling
- Basic Problem Solving

## ▶️ How to Run

1. Make sure Python 3 is installed.

2. Download or clone this repository.

3. Run:

```bash
python calculator.py
```

---

## 🖥️ Project Demo

The application runs through a command-line interface (CLI).

Example:

```
Simple Calculator

1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)
5. Exit

Enter choice: 1

Enter first number: 10
Enter second number: 5

Result: 15
```
